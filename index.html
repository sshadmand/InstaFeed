A FEW LINES TO GET STARTED

Your app. One little addition.

Read the documentation ↗
01 / INSTALL THE SDK

Bring InstaFeed into your app.

Install from GitHub. The package and import name are feedback-fab.

TERMINAL
npm install github:sshadmand/feedback-fab
02 / ADD THE WIDGET

Initialize after your page loads.

Point it at your feedback API and give your app a name. It works with plain JavaScript or your favorite framework.

For React, create it in an effect and call widget.destroy() during cleanup.

JAVASCRIPT / TYPESCRIPT
import { createFeedbackFab } from 'feedback-fab';

const widget = createFeedbackFab({
  endpoint: 'https://your-feedback-api.vercel.app',
  appName: 'My app',
});
↗
03 / CONNECT YOUR FEEDBACK INBOX

Host the API. Keep the feedback yours.

Import the repository into Vercel, connect Neon Postgres, and set DATABASE_URL and FEEDBACK_REVIEW_TOKEN. Use your deployment URL as the SDK endpoint. The included review inbox opens at /review.html with your review token.

Set FEEDBACK_ALLOWED_ORIGINS to limit submissions to your app’s domains.

Deploy guide ↗

Made to fit into your app.

The widget isolates its styles with Shadow DOM. Choose a specific element to capture, handle submission callbacks, or remove the widget when a component unmounts.

Know what gets captured.

Reports include the screenshot, page URL, title, and browser details. Cross-origin iframes and protected media may not appear. Use it on pages your testers are comfortable sharing.
